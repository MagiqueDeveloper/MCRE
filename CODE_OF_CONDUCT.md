# Code of Conduct

Treat other contributors and players with respect. Discuss the work on its merits, make room for newcomers, and give credit for contributions. Harassment, personal attacks, discrimination, unwanted sexual attention, threats, and publishing someone’s private information are grounds for moderation.

This applies to the project’s issues, pull requests, discussions, and other spaces the project runs. Contact a maintainer privately using the contact details on their GitHub profile. For urgent threats or abuse on GitHub, use [GitHub’s abuse report form](https://support.github.com/contact/report-abuse). Maintainers may remove content, restrict participation, or block accounts as appropriate.
