# MCRE · Minecraft: Rust Edition

Community mods for [Horizon](https://github.com/horizon-rust/horizon), the Rust implementation of Minecraft: Java Edition. MCRE is an independent project.

| Mod | What it does | Builds |
| --- | --- | --- |
| [Horizon Acoustics](mods/horizon-acoustics) | Wall muffling and room reverb for positional sounds | [Apple Silicon preview](https://github.com/MagiqueDeveloper/MCRE/releases/tag/horizon-acoustics-v0.1.0) |

Check each mod’s compatibility notes before installing. Each mod has its own source, build instructions, license, and release tags.

[Report a bug or suggest a port](https://github.com/MagiqueDeveloper/MCRE/issues/new/choose), [ask in Discussions](https://github.com/MagiqueDeveloper/MCRE/discussions), or read the [contributor guide](CONTRIBUTING.md) to start a pull request.
