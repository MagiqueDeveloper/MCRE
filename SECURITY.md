# Security

Use [GitHub private vulnerability reporting](https://github.com/MagiqueDeveloper/MCRE/security/advisories/new) to report a security issue in an MCRE mod. Include the affected mod and version, Horizon version, impact, and steps to reproduce. Remove credentials and other private data from any logs.

Use the [bug report form](https://github.com/MagiqueDeveloper/MCRE/issues/new/choose) for ordinary crashes and gameplay issues.
